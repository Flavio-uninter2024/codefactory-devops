# CodeFactory DevOps

Aplicação desenvolvida para a disciplina de DevOps, com o objetivo de demonstrar práticas de controle de versão, branches, Pull Requests, resolução de conflitos e integração contínua.

## Tecnologias

- Python
- Flask
- Git
- GitHub

## Funcionalidades

- Página inicial da aplicação
- Endpoint de saúde /health
- Endpoint de informações /info

## Branches

- main — versão principal
- desenvolvimento — desenvolvimento da aplicação
- feature — implementação de funcionalidades
- feature-conflito — demonstração de conflito e resolução de merge
